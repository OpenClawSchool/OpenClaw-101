## Day 1 — 마크다운 문법: AI가 가장 좋아하는 글쓰기

### 오늘의 개념

마크다운(.md)은 `#`, `-`, `**` 같은 간단한 기호로 문서 구조를 표현하는 형식입니다. 사람이 읽기에도 깔끔하지만, **AI가 문서의 구조(제목, 목록, 표)를 오해 없이 파악할 수 있다**는 점이 핵심입니다. 옵시디언의 모든 노트는 마크다운으로 저장됩니다.

### 오늘 익힐 문법 6종

| 문법 | 쓰는 법 | 결과 |
| :-- | :-- | :-- |
| 제목 | `# 큰제목` `## 중간제목` `### 소제목` | 문서의 뼈대 |
| 강조 | `**굵게**` `*기울임*` | **굵게**, *기울임* |
| 목록 | `- 항목` / `1. 항목` | 순서 없는/있는 목록 |
| 인용 | `> 인용문` | 인용 블록 |
| 코드 | `` `코드` `` / ` ``` ` 블록 | 코드 표시 |
| 표 | `\| 열1 \| 열2 \|` | 표 |

### 미션 (20~30분)

1. 옵시디언을 열고 Vault에 `자기소개.md` 노트를 새로 만듭니다.
2. 아래 내용을 담되, **위 문법 6종을 최소 한 번씩 모두 사용**해서 작성합니다.
   - 이름과 나의 전문 분야 (제목)
   - 이 분야를 선택한 이유 (인용문으로 나의 다짐 한 줄 포함)
   - 내가 아는 것 3가지 / 배우고 싶은 것 3가지 (목록)
   - 나의 학습 계획 (표)
3. 편집 모드와 읽기 모드(우측 상단 책 아이콘)를 전환하며 결과를 확인합니다.

> **💡 TIP:** 문법이 기억나지 않으면 에이전트에게 물어보세요.
> ```
> 마크다운 표 문법 예시 보여줘
> ```

### 완료 체크리스트

- [ ] 문법 6종을 모두 사용한 노트 1개 완성
- [ ] 읽기 모드에서 표와 목록이 깨지지 않고 표시됨

## Day 2 — 노트 작성: AI 친화적 구조로 지식 만들기

### 오늘의 개념

좋은 노트는 "한 노트에 한 가지 지식"을 담습니다. 그리고 AI가 정확히 정보를 추출하도록 2차시에서 배운 **4단 구조**를 따릅니다.

| 단계 | 필수 요소 | 설명 |
| :-- | :-- | :-- |
| **Topic** | 제목 | 무엇에 대한 지식인지 명확한 키워드 |
| **Concept** | 개념 정의 | 초등학생도 이해할 수 있는 원리 설명 |
| **Example** | 실전 사례 | 구체적인 활용 예시나 데이터 |
| **Checklist** | 검증 방법 | 확인 사항이나 단계별 가이드 |

### 미션 (20~30분)

1. 나의 전문 분야에서 **가장 자주 받는 질문 2개**를 고릅니다. (2차시 질문 로드맵 20개에서 골라도 좋습니다.)
2. 각 질문에 답하는 노트를 1개씩, 총 **2개** 작성합니다. 반드시 4단 구조(Topic-Concept-Example-Checklist)를 헤더(`##`)로 구분해 작성하세요.
3. 파일명은 노트의 Topic이 그대로 드러나게 짓습니다. (예: `영어 발음 교정 3단계.md`)

> **💡 TIP:** 막막하면 초안을 에이전트와 함께 잡아보세요. 단, Example(실전 사례)만큼은 **나의 경험**으로 채워야 진짜 전문가 지식이 됩니다.

### 완료 체크리스트

- [ ] 4단 구조를 지킨 노트 2개 완성
- [ ] 각 노트가 "질문 하나에 답 하나" 원칙을 지킴

## Day 3 — [[링크]]와 백링크: 지식을 그물로 엮기

### 오늘의 개념

옵시디언의 진짜 힘은 폴더가 아니라 **링크**에 있습니다. 노트 안에서 `[[노트제목]]`을 입력하면 두 노트가 연결되고, 상대 노트에는 자동으로 **백링크**(나를 참조한 노트 목록)가 생깁니다. 링크가 쌓이면 지식이 낱장 문서가 아닌 '그물망'이 됩니다.

- `[[노트제목]]` — 다른 노트로 연결
- `[[노트제목|표시할 텍스트]]` — 표시 문구를 바꿔서 연결
- 우측 패널의 **백링크** 탭 — 이 노트를 참조하는 노트들을 확인

### 미션 (20~30분)

1. `_허브.md`(또는 `나의 전문분야 지도.md`) 노트를 만듭니다. 내 지식의 대문 역할을 하는 **허브 노트**입니다.
2. 허브 노트에 지금까지 만든 모든 노트를 `[[링크]]`로 나열하고, 각 링크 옆에 한 줄 설명을 답니다.
3. Day 2에서 만든 노트 2개를 열어, 본문 중 서로 관련된 개념에 `[[링크]]`를 최소 1개씩 걸어줍니다.
4. 아무 노트나 열고 백링크 탭에서 "누가 나를 참조하는지" 확인합니다.

> **💡 TIP:** 아직 없는 노트도 `[[미래의 노트]]`처럼 링크를 먼저 걸 수 있습니다. 링크가 회색으로 표시되며, 클릭하면 그 자리에서 새 노트가 생성됩니다. "앞으로 써야 할 지식"을 예약하는 방법입니다.

### 완료 체크리스트

- [ ] 허브 노트 1개 완성 (모든 노트로 향하는 링크 포함)
- [ ] 노트 간 상호 링크 최소 2개 생성
- [ ] 백링크 탭으로 역참조 확인 완료

## Day 4 — 태그와 검색: 지식에 이름표 붙이기

### 오늘의 개념

**링크**가 노트와 노트의 '관계'라면, **태그**는 노트의 '속성'입니다. 노트 어디서든 `#태그`를 입력하면 붙습니다. `#영어/발음`처럼 `/`로 계층 태그도 만들 수 있습니다. 태그를 클릭하면 같은 태그가 붙은 노트가 모두 검색됩니다.

태그는 미리 규칙을 정하지 않으면 `#영어공부`, `#영어`, `#english`처럼 뒤죽박죽이 되기 쉽습니다. 그래서 오늘의 핵심은 **나만의 태그 체계표**를 만드는 것입니다.

### 미션 (20~30분)

1. `태그 체계.md` 노트를 만들고, 내 전문 분야에 맞는 태그 규칙을 표로 정리합니다. 태그는 **5~8개면 충분**합니다. 예시:

   | 태그 | 용도 |
   | :-- | :-- |
   | `#개념` | 원리와 정의를 담은 노트 |
   | `#사례` | 실전 예시 중심 노트 |
   | `#체크리스트` | 단계별 가이드 노트 |
   | `#질문` | 아직 답을 못 채운 예상 질문 |

2. 지금까지 만든 **모든 노트**를 열어 체계표에 맞는 태그를 붙입니다.
3. 좌측 검색(돋보기)에서 `tag:#개념` 으로 검색해 태그별로 노트가 모이는지 확인합니다.

> **💡 TIP:** 태그가 10개를 넘어가면 오히려 안 쓰게 됩니다. 고민되면 태그를 새로 만들지 말고 기존 태그를 재사용하세요.

### 완료 체크리스트

- [ ] 태그 체계표 노트 1개 완성 (태그 5~8개)
- [ ] 모든 기존 노트에 태그 부착
- [ ] `tag:` 검색으로 필터링 성공

## Day 5 — 그래프 뷰: 내 지식의 지도를 보다

### 오늘의 개념

**그래프 뷰**(좌측 리본의 별자리 모양 아이콘, 단축키 `Ctrl+G`)는 Vault의 모든 노트와 링크를 별자리처럼 시각화합니다. 여기서 두 가지를 발견할 수 있습니다.

- **고아 노트(Orphan):** 어떤 노트와도 연결되지 않고 홀로 떠 있는 점 → 링크를 걸어줘야 할 노트
- **빈틈(Gap):** 뭉쳐 있는 지식 덩어리들 사이의 빈 공간 → 새로 써야 할 지식

그래프는 "내가 무엇을 아는가"보다 **"내가 무엇을 모르는가"**를 보여주는 도구입니다.

### 미션 (20~30분)

1. 그래프 뷰를 열고 내 Vault의 현재 모습을 관찰합니다. 스크린샷을 찍어 보관하세요. (6일 뒤, 한 달 뒤와 비교하는 재미가 있습니다.)
2. **고아 노트**를 찾아 관련 노트 또는 허브 노트와 링크로 연결합니다.
3. 그래프를 보며 "여기 사이에 있어야 할 지식이 뭐지?"를 하나 찾아, 그 주제로 **신규 노트 1개**를 4단 구조로 작성하고 링크를 겁니다.

> **💡 TIP:** 그래프 뷰 설정에서 '기존에 없는 파일(존재하지 않는 링크)' 표시를 켜면, Day 3에서 예약해 둔 회색 링크들이 함께 보입니다. 앞으로 채워야 할 지식의 지도가 됩니다.

### 완료 체크리스트

- [ ] 그래프 뷰 스크린샷 저장
- [ ] 고아 노트 0개 만들기
- [ ] 빈틈을 메우는 신규 노트 1개 작성 및 연결

## Day 6 — PARA 폴더 구조: Vault를 시스템으로 완성하기

### 오늘의 개념

마지막 날은 지금까지 쌓인 노트를 **행동 기준**으로 재배치합니다. 2차시 보충 자료에서 배운 PARA 기법입니다.

- **P (Projects):** 목표와 기한이 있는 일 (예: 전문가 에이전트 만들기)
- **A (Areas):** 기한 없이 계속 관리할 영역 (예: 나의 전문 분야)
- **R (Resources):** 관심 있는 학습 주제·참고 자료
- **A (Archives):** 끝났거나 안 쓰는 것들의 보관소

핵심은 완벽한 분류가 아니라 **유연한 이동**입니다. 프로젝트가 끝나면 Archive로 옮기면 그만입니다.

### 미션 (20~30분)

1. Vault에 PARA 폴더 4개를 만듭니다. 에이전트에게 맡겨도 됩니다.
   ```
   옵시디언 파라 기법 폴더 만들어줘
   ```
2. 지금까지 만든 노트를 전부 PARA 폴더로 이동합니다. 판단 기준은 "이 노트는 어떤 **행동**에 필요한가?" 하나면 충분합니다. 30초 이상 고민되면 일단 Resources에 넣으세요.
3. 허브 노트를 열어 링크가 깨지지 않았는지 확인합니다. (옵시디언은 파일을 옮겨도 `[[링크]]`를 자동으로 유지해 줍니다 — 직접 확인해 보세요.)
4. 마지막으로 그래프 뷰를 열어 6일 전과 달라진 내 지식의 지도를 감상합니다.

### 완료 체크리스트

- [ ] PARA 폴더 4개 생성
- [ ] 모든 노트를 PARA 기준으로 배치
- [ ] 폴더 이동 후에도 링크 정상 작동 확인
